## Cohesive build passes

1. Inspect repository, permissions, environment, current access contracts, and migrations. Identify what is reused versus new.
2. Implement tenant/property access, profile, evidence/record schema, versioning, and sample UI with unmistakable fixtures.
3. Implement the shared research engine and all three playbooks with bounded source retrieval, schema validation, deduplication, and budget accounting.
4. Connect baseline creation, scheduled updates, run statuses, saved/dismissed state, exports, and assisted setup/admin views.
5. Validate the complete flow with fixtures and focused security/cost tests. Run live research only when authorized and credentials/budgets exist. Use approved deployed Vercel testing for this user's application when available; do not substitute local browser testing against their preference.
6. Report actual readiness and any blockers. Skill creation alone is not approval to deploy code, provision services, or run the Seattle/Portland pilots.

## Acceptance cases

- Five sources describing one project create one record, preserve lineage, and produce one alert.
- A named contractor added later updates that record with a clear factual change.
- Syndicated text or a refreshed crawl timestamp produces no new-demand alert.
- A local employer without travel evidence remains a factual company record with explicitly uncertain lodging relevance.
- An event's new annual edition does not overwrite the previous edition's dates.
- Cancellation/completion updates status; missing sources produce uncertainty, not invented verification.
- A quiet completed cycle shows no meaningful changes without manufacturing records.
- A source outage/budget cutoff shows partial coverage and preserves last successful data.
- Opening an agent, searching, and exporting never starts paid model research.
- A user cannot access another tenant/property via URLs, exports, jobs, cache entries, or changed request parameters.
- Concurrent jobs cannot independently spend the same remaining budget; retries cannot duplicate findings or notifications.
- Source prompt injection cannot change system instructions, execute arbitrary tools, or disclose credentials/private hotel data.
- CSV formulas are neutralized and dates/source links survive export.
- All three scout cards route to working category coverage; demo-only results are not represented as production research.
