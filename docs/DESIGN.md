# Pass 1 interface system

Warm-white canvas #f7f6f0, forest navigation #173e32, near-black text #19251f, antique-gold accents #a58b46. Georgia display headings with system sans-serif controls. A 232px navigation rail, generous page gutters, thin warm-gray rules, 8px corners, readable tables and restrained status labels. Mobile uses an expandable navigation header and stacked finding rows. Icons use Lucide with text labels.

Primary concept: `design/overview-concept.png`, generated with the built-in image tool. Prompt: SCOUT hotel market research Overview, warm white / forest / restrained gold, editorial typography, fictional demo banner, property context, three summary counts, recent intelligence table, coverage and quiet-cycle sidebar. No CRM, revenue claims, charts or live research. The generated image is a visual reference only; all interface content and controls are native HTML/React.

The same components extend to the public service page (editorial headline, sample deliverable, scout explanations, setup, price and local briefing form), blueprint (filter toolbar and table), details (facts, inference, evidence and history), agents (findings/coverage/history tabs), updates (dated timeline), exports (shared table), and profile/setup (labeled forms and review steps).

Intentional content corrections: all fixture dates and source statements come from the typed dataset; no generated image dates or inferred visitation claims are copied as facts. Counts are derived. No decorative hotel-switcher control without a function.

Browser fidelity and responsive acceptance remain pending an authorized Vercel deployment, per the user's explicit preference. No local browser acceptance was performed and no visual sign-off is claimed.
