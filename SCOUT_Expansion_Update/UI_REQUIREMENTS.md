# UI additions
Retain the current refined interface, approved logo/icon, forest green, warm white and gold. No broad redesign.

## Navigation proposal for implementation
Preserve Overview, Market Blueprint, Research Agents, Updates, Exports and Hotel Profile. Add Briefing as a primary destination. Extend Research Agents with Competitor SCOUT and Property SCOUT cards and details. Add category filters to shared findings where supported without mixing competitor activity with confirmed prospecting demand.

## Hotel Profile
Add a Comp set section: explicit named property selection/entry, address/locality, official domain and aliases, active membership and edit controls appropriate to existing roles. Add own-hotel aliases/domain to matching configuration. Validate duplicates and incomplete identity; no silent nearby-hotel discovery. Do not impose an invented hard competitor limit; obtain an approved plan limit before live activation.

## Agent views
Reuse Findings / Coverage / Run history. Competitor findings identify the selected hotel and change type. Property findings identify source, publication/discovery date, sentiment context and identity confidence. Coverage states explain accessible sources and unavailable classes. Avoid claims of full review/social coverage.

## Overview
Show useful developments across prospecting, comp set and own property, with dated counts. Add latest brief timestamp/status and Generate fresh brief action. Do not label a stored snapshot “live.” Preserve compact layout and accessible mobile navigation.

## Briefing
Provide Generate fresh brief and View last brief. Show estimated maximum permitted spend/usage where needed for an informed choice, without exposing internal model implementation.
Show refresh progress by category, join existing jobs on repeated clicks, and keep prior brief readable while refreshing. Show actionable partial/budget/setup messages. Present the brief in scannable sections with linked sources and a clear distinction between facts and implications. Include Copy and print/download using existing export infrastructure; retain snapshot timestamps and citations.

## States
Design empty initial setup, no comp set, no mentions, zero material changes, ongoing context, disabled live mode, refresh in progress, partial coverage, budget exhausted, source unavailable and failed refresh. Do not confuse “not checked” with “nothing found.” Synthetic mode must be obvious on screen and export.

## Exports and accessibility
Extend existing export types for new categories; preserve source links, dates, evidence status and inference labels. Use keyboard-operable filters and disclosures, visible focus, readable metadata and non-color-only statuses. Verify desktop and 390px/320px layouts on authorized Vercel deployments.
